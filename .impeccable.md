## Design Context

### Users
AI agents (via CLI / MCP / skill) and the operators/builders who wire them — technical, fast-moving, allergic to marketing fluff. They are routing real tool calls, watching spend + reliability, debugging failures. Context: terminal-adjacent, many tabs open, value speed and honesty.

### Brand Personality
Honest, precise, electric. "Every number is real." Serious infrastructure that still feels alive. Three words: **precise · electric · honest**. The blue is signal, not decoration.

### Aesthetic Direction
Light cool-grey editorial — `#E2E5E8` page, white cards, one electric-azure accent (`#2E9BFF`). Serif display accents (Newsreader italic) over Inter Tight body, JetBrains Mono for data/tables/code. Editorial bento composition (asymmetric, swiss-line dividers), not uniform card grids. Live telemetry as the credible version of "we have tools." References: aegntic.ai robot-arm glow, editorial magazine grids. **Anti-references (AI slop — never):** cyan-on-dark, purple→blue gradients, gradient text, glassmorphism, glow borders, generic icon-card grids, overused fonts (Inter/Roboto as the whole stack), sparkline decoration, "cute" empty states.

### Design Principles
1. **Every number is real** — never fake a metric or pad a stat. Reliability/pricing come from live data or they don't appear.
2. **Delight amplifies, never blocks** — motion < 1s, skippable, `prefers-reduced-motion` respected. Never delay a core action.
3. **Subtle sophistication over flash** — one well-orchestrated moment beats scattered confetti. Exponential easing (ease-out-quart/expo); transform + opacity only.
4. **Dry, precise copy** — no exclamation marks, no wacky metaphors, no AI-slop loading jokes ("herding pixels"). Say what happened, sparely.
5. **Motion conveys state** — entrances, feedback, success/failure. Movement explains; it doesn't decorate.

### Delight calibration (2026-07-26)
Intensity: **subtle / sophisticated**. Copy: **dry + precise**. Sound: **none** (dev tool, many tabs).
